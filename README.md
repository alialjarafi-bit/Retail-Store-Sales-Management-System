# Retail Store Sales Management System

## Project Overview
A Microsoft Access-based system designed to manage retail store sales and inventory efficiently.

The project focuses on organizing product information, categories, invoices, and inventory records in one place.

## Key Features
- Product and category management.
- Sales and invoice tracking.
- Inventory management.
- Stock alerts.
- Search forms.
- Sales and inventory reports.

## Technologies
- Microsoft Access
- Database Management

## Purpose
This project demonstrates the practical application of database concepts to retail sales and inventory management.
